# 模型定义文档

## 概述

Perigon.PostgreSQL 使用 C# POCO 类定义数据模型。模型通过源码生成器自动发现，无需手动编写注册代码。

有两种模型定义方式：

- **约定定义（Convention）** — 按命名规则自动映射表名、列名、主键。
- **特性定义（Attribute）** — 通过标准 `System.ComponentModel.DataAnnotations.Schema` 特性（`[Table]`、`[Column]`、`[Key]`、`[DatabaseGenerated]`、`[NotMapped]` 等）精确控制映射。

---

## 基础模型（约定定义）

```csharp
public sealed class User
{
    public int Id { get; set; }              // 主键 → "id"，自增
    public string UserName { get; set; } = ""; // → "user_name"
    public int Age { get; set; }             // → "age"
    public bool IsActive { get; set; }       // → "is_active"
    public string? Status { get; set; }      // → "status"
    public DateTime CreatedAt { get; set; }  // → "created_at"
    public DateTime? UpdatedAt { get; set; } // → "updated_at"
}
```

### 约定规则

| 规则 | 示例 | 结果 |
|------|------|------|
| 表名 | `User` | `users`（类名转蛇形 + s） |
| 列名 | `UserName` | `user_name`（属性名转蛇形） |
| 主键 | `Id` 或 `{TypeName}Id` | 自动识别为主键 |
| 自增 | 主键且类型为 int/long/short | 默认 `GENERATED ALWAYS AS IDENTITY` |

单列 Guid 主键不会创建 PostgreSQL identity。结构化插入时，如果 单列 Guid 主键为 `Guid.Empty`，
库会在客户端赋值 `Guid.CreateVersion7()`；非默认 Guid 会保留。原生 SQL 不经过该赋值
逻辑，需要调用方自行提供主键。

## 显式模型定义（特性）

```csharp
using System.ComponentModel.DataAnnotations;
using System.ComponentModel.DataAnnotations.Schema;

[Table("app_users", Schema = "security")]
public sealed class AppUser
{
    [Key]
    [DatabaseGenerated(DatabaseGeneratedOption.Identity)]
    [Column("user_id")]
    public int Key { get; set; }

    [Column("display_name")]
    public string Name { get; set; } = "";

    [Column("email")]
    public string Email { get; set; } = "";

    [DatabaseGenerated(DatabaseGeneratedOption.Computed)]
    [Column("score")]
    public int? ComputedScore { get; set; }

    [NotMapped]
    public string RuntimeOnly { get; set; } = "";
}
```

### 标准 DataAnnotations 特性

映射特性直接使用 .NET SDK 自带的 `System.ComponentModel.DataAnnotations` / `System.ComponentModel.DataAnnotations.Schema`，
库内不再重复定义同名特性。

| 特性 | 说明 |
|------|------|
| `[Table]` | 第一个参数为表名，`Schema` 指定数据库 schema，默认 `public` |
| `[Column]` | 第一个参数为列名（不指定则使用约定蛇形名称），`TypeName` 指定数据库类型名（例如 `jsonb`） |
| `[Key]` | 标记主键；多个属性同时标记即为复合主键 |
| `[DatabaseGenerated(DatabaseGeneratedOption.Identity)]` | 标记自增列 |
| `[DatabaseGenerated(DatabaseGeneratedOption.Computed)]` | 标记数据库生成列（INSERT 时不发送该列的值） |
| `[DatabaseGenerated(DatabaseGeneratedOption.None)]` | 关闭主键的默认自增行为 |
| `[NotMapped]` | 标记该属性或类型不参与数据库映射 |
| `[MaxLength]` / `[StringLength]` / `[Required]` | 列长度与非空约束 |

数据库类型名也可通过 Fluent API `HasColumnType("jsonb")` 指定，两者等价。

## 数组与列表

`int[]`、`string[]`、`List<string>`、`List<int>` 等类型**默认自动映射**为 PostgreSQL 数组列，无需额外特性。

```csharp
public sealed class Article
{
    public int Id { get; set; }

    public string Title { get; set; } = "";

    // 自动映射为 text[]（PostgreSQL 字符串数组）
    public string[] Tags { get; set; } = [];

    // 自动映射为 integer[]
    public List<int> Scores { get; set; } = [];

    // 可为 null 的数组
    public int[]? OptionalIds { get; set; }
}
```

支持的数组类型：

| C# 类型 | PostgreSQL 类型 |
|---------|----------------|
| `int[]` | `integer[]` |
| `long[]` | `bigint[]` |
| `short[]` | `smallint[]` |
| `string[]` | `text[]` |
| `bool[]` | `boolean[]` |
| `DateTime[]` | `timestamp with time zone[]` |
| `List<T>` | 对应 `T[]` |

> 注意：`List<T>` 属性需要 `=` 初始化或在构造函数中初始化，否则查询返回时可能为 null。推荐使用 `= [];` 默认值。

## JSONB 列

通过 `[Column(TypeName = "jsonb")]` 标记 JSONB 列。C# 侧通常使用 `string` 类型。

```csharp
using System.ComponentModel.DataAnnotations.Schema;

public sealed class Product
{
    public int Id { get; set; }

    public string Name { get; set; } = "";

    [Column(TypeName = "jsonb")]
    public string? Attributes { get; set; }
}
```

使用 JSONB 查询方法（`JsonbContains`、`JsonbHasKey`、`JsonbText`、`JsonbPathExists`），参见查询文档。

## 自增与生成列

### 身份列（Identity）

默认情况下，类型为 `int`/`long`/`short` 的主键属性会自动被识别为身份列，生成：
```sql
id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY
```

通过 `[DatabaseGenerated(DatabaseGeneratedOption.None)]` 可禁用此行为。

### 生成列（Computed / Generated）

通过 `[DatabaseGenerated(DatabaseGeneratedOption.Computed)]` 标记数据库端生成的值列（如默认值、计算列），INSERT 时不会发送该列的值。

```csharp
[DatabaseGenerated(DatabaseGeneratedOption.Computed)]
[Column("slug")]
public string? Slug { get; set; }
```

## 自动时间字段

`AutoTimestampAttribute` 和 `HasAutoTimestamp` 为结构化写入提供客户端 UTC 时间：

```csharp
using Perigon.PostgreSQL.Attributes;

public sealed class AuditEntry
{
    public Guid Id { get; set; }

    [AutoTimestamp(onInsert: true)]
    public DateTimeOffset CreatedAt { get; set; }

    [AutoTimestamp(onInsert: false, onUpdate: true)]
    public DateTimeOffset UpdatedAt { get; set; }
}
```

等价的 Fluent 配置：

```csharp
modelBuilder.Entity<AuditEntry>(entity =>
{
    entity.Property(item => item.CreatedAt).HasAutoTimestamp(onInsert: true);
    entity.Property(item => item.UpdatedAt).HasAutoTimestamp(onInsert: false, onUpdate: true);
});
```

插入时仅填充默认值时间字段，调用方预先设置的值不会被覆盖。更新时，`onUpdate` 字段
会由 `ExecuteUpdateAsync` 自动赋值当前 UTC 时间；同一次更新显式设置该字段时，以显式
值为准。该功能不使用变更追踪。`SqlCommand`、`SqlQuery` 和其他原生 SQL 不经过该
策略。

## 可空性

| C# 类型 | 数据库类型 | NULL 约束 |
|---------|-----------|-----------|
| `int` | `integer` | `NOT NULL` |
| `int?` | `integer` | 无 NOT NULL（即可空） |
| `string` | `text` | `NOT NULL` |
| `string?` | `text` | 可空 |
| `int[]` | `integer[]` | `NOT NULL` |
| `int[]?` | `integer[]` | 可空 |

## 复合主键

通过 `[Key]` 标记多个列来定义复合主键：

```csharp
public sealed class OrderItem
{
    [Key]
    public int OrderId { get; set; }

    [Key]
    public int ItemIndex { get; set; }

    public string ProductName { get; set; } = "";

    public int Quantity { get; set; }
}
```

## 完整示例

```csharp
using System.ComponentModel.DataAnnotations.Schema;

[Table("blog_posts", Schema = "content")]
public sealed class BlogPost
{
    public int Id { get; set; }

    public string Title { get; set; } = "";

    [Column("body_md")]
    public string Markdown { get; set; } = "";

    [Column(TypeName = "jsonb")]
    public string? Metadata { get; set; }

    public string[] Tags { get; set; } = [];

    public List<string> Contributors { get; set; } = [];

    [Column("is_published")]
    public bool? Published { get; set; }

    [DatabaseGenerated(DatabaseGeneratedOption.Computed)]
    public DateTime? PublishedAt { get; set; }

    public DateTime CreatedAt { get; set; }

    [NotMapped]
    public string TempDraft { get; set; } = "";
}
```

生成的表结构：

```sql
CREATE TABLE content.blog_posts (
    id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    title text NOT NULL,
    body_md text NOT NULL,
    metadata jsonb,
    tags text[] NOT NULL,
    contributors text[] NOT NULL,
    is_published boolean,
    published_at timestamp with time zone,
    created_at timestamp with time zone NOT NULL
);
```

## 在 DbContext 中注册

模型在 `DbContext` 子类中通过 `DbSet<T>` 属性暴露：

```csharp
using Perigon.PostgreSQL;

public sealed class AppDbContext : DbContext
{
    public AppDbContext(string connectionString)
        : base(builder => builder.UsePostgres(connectionString))
    {
    }

    public DbSet<User> Users => Set<User>();
    public DbSet<BlogPost> Posts => Set<BlogPost>();
    public DbSet<OrderItem> OrderItems => Set<OrderItem>();
}
```

### 7.2.1 全局查询过滤器

租户隔离、软删除等查询约束可在 `OnModelCreating` 中注册为具名过滤器：

```csharp
public sealed class AppDbContext : DbContext
{
    private readonly Guid _tenantId;

    public DbSet<User> Users => Set<User>();

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        HasQueryFilter("Tenant", (User user) => user.TenantId == _tenantId);
        HasQueryFilter("NotDeleted", (User user) => !user.IsDeleted);
    }
}
```

`Set<User>()` 默认应用全部过滤器，多个过滤器会组合到 SQL 条件中。需要明确跳过
部分过滤器时使用 `SetWithoutFilters<User>("NotDeleted")`；需要跳过全部过滤器时使用
`SetIgnoringAllFilters<User>()`。具名过滤器名称会被校验，空列表或未知名称不会被
当作“全部跳过”。过滤器只影响查询；原生 SQL 不会自动应用过滤器，且租户字段在新增
和批量写入时的赋值、校验由应用负责。

所有 `DbSet<T>` 属性中的实体类型会被源码生成器自动发现并生成注册代码。
